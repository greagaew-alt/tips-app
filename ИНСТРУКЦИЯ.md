# «Чаевые» — как запустить

Приложение уже залито на GitHub Pages (ссылку дал в чате). Сервера и базы нет:
данные каждого пользователя хранятся в его аккаунте Телеграма (CloudStorage) и
синхронятся между устройствами. Добавить коллегу = просто дать ему бота.

От тебя нужно один раз создать бота и привязать к нему ссылку. 3 шага, ~3 минуты.

---

## Шаг 1. Создать бота

1. В Телеграме напиши [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Придумай имя (например `Чаевые`) и username (заканчивается на `bot`, например `gleb_tips_bot`)
4. BotFather пришлёт токен — он тут больше нигде не нужен, просто не теряй.

## Шаг 2. Привязать приложение

1. Снова [@BotFather](https://t.me/BotFather) → `/mybots` → выбери своего бота
2. **Bot Settings** → **Menu Button** → **Edit menu button URL**
3. Вставь ссылку на приложение (из чата, вида `https://ИМЯ.github.io/tips-app/`)
4. Подпись кнопки — например `Открыть`

## Шаг 3. Проверить

1. Открой своего бота, нажми кнопку меню слева от поля ввода.
2. Открылось приложение — отметь смену на вкладке «Смены», запиши чаевые.
3. Закрой, открой заново — цифры на месте. Открой с другого устройства под тем же
   аккаунтом — данные подтянутся.

Готово.

---

## Как дать коллеге

Просто скинь ему ссылку на бота (`t.me/твой_бот`). Он жмёт «Запустить», потом
кнопку меню — и у него своё приложение со своими цифрами. Ваши данные не
пересекаются: у каждого хранится в его аккаунте Телеграма.

## Если ставки на работе поменяются

Числа `2500 / 2000 / 21` заданы в `index.html`, вверху скрипта, блок
`ПРАВИЛА ОПЛАТЫ`. Скажи мне новые — поправлю и перезалью.

## Посмотреть вид на компе

Дважды кликни `index.html` — откроется в браузере на примерных данных
(демо-режим, хранится в браузере). На GitHub Pages это не влияет.
